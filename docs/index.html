Como pesquisar com critério

1. Leia a pergunta

Use uma questão específica. Assim você pode comparar as respostas obtidas em IAs diferentes.

2. Confira as fontes

Peça documentos originais, datas e trechos pertinentes. Uma mesma prova reproduzida em vários textos não vira várias provas.

3. Teste a conclusão

Examine a melhor objeção, identifique o que permanece incerto e decida se as evidências sustentam a resposta.

Leia os critérios editoriais completos.

Encontrou um erro?

Abra uma questão no repositório com o trecho, a correção proposta e uma fonte verificável. Para enviar, é necessária uma conta no GitHub.
